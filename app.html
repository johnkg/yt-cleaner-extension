Combine playlists

Moves every video from the checked playlists on the left into one target playlist (duplicates already in the target are skipped). Each video moved costs 50 API units, so combining large playlists uses a lot of your daily quota — you'll see the total before anything happens.

Browse playlist by creator

Groups one playlist's videos by the channel that uploaded them, so you can select everything from a creator at once and move or delete it in bulk. Loading the list is free — it uses data already fetched. Moving costs 100 API units per video (add + remove); deleting costs 50.

Find videos by duration

Finds videos in one playlist that are shorter or longer than you want — useful for clearing out Shorts, or for pulling long talks into their own playlist. Leave a box blank to leave that end open. Scanning costs about 2 API units per 50 videos; moving costs 100 per video and deleting 50.

Find videos saved in multiple playlists

Scans the checked playlists on the left for videos that appear in more than one of them. For each duplicate you can keep one copy and remove the others. Scanning is cheap (reading only); each copy you remove costs 50 API units.
